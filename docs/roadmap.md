# Roadmap

Build the riskiest part (voice) first, the dashboard last.

| Phase | Time (1 dev) | What gets built | Done when |
|---|---|---|---|
| 1. Voice | ~2 weeks | One real call to your own phone in Hinglish, outcome saved | The call sounds natural and replies start in under ~1s |
| 2. Shopify + scheduler | ~2 weeks | Order → call → Shopify tag, with retries and calling hours | 100 real orders from one pilot brand |
| 3. Dashboard | ~2–3 weeks | Login, calls list, recordings, script editor (design from `dashboard/prototype/`) | A seller can see everything without your help |
| 4. Wallet + self-serve | ~1–2 weeks | Razorpay, self-serve onboarding, admin panel | A new seller goes live on their own |

**Shortcut:** after Phase 2, take pilot customers before the dashboard exists. Set them up
yourself and send results in a Google Sheet. This shows whether sellers will pay before you
build the UI.

## Version 2 (after paying customers)

WhatsApp fallback when a call isn't answered · NDR and abandoned-cart templates ·
WooCommerce and Shiprocket · team member logins · Tamil, Telugu, Bengali, Marathi ·
transfer to a human · cancel-rate by pincode report

## Later

"Describe it and AI builds it" script editing · drag-and-drop builder for advanced users ·
JustDial lead callback · agency/reseller panel · public API
